# Launch asset manifest (S-072)

Every file the launch kit uses, listed in place. Nothing is copied or edited, so the hash cannot drift from the source. Only real assets appear: brand files drawn by `design/brand/build.py`, screenshots that a test script rendered from the app, and the site's own Open Graph image and hero films. No stock images, no hand drawn mock-ups.

Notes:

- The logo is the saguaro cactus built from hive cells (`kawaro-cells*.svg`, `wordmark*.svg`); the single cell with the cactus cut out is the app icon (`png/kawaro-*.png`). See `design/brand/README.md` and `docs/adr/0008-name-kawaro.md`.
- The four screenshots are the Settings window, General page, at the default 880 x 640 size. The Arabic ones show the right to left layout (rail on the right, text right aligned). They were genuinely recaptured on 2026-11-05 from the `settings_snapshot` renderer in private headless KWin, with `--page 0 --size 880x640` and each language/theme pair. The header shows the version label 0.5.1, the workspace version at capture time. Four matching test references were independently regenerated by `crates/ui/tests/settings_snapshots.sh --update`. The images are unedited; a later version needs new renders, not a changed label or copied old frame.
- A by eye check of all four listed screenshots and their four test-reference counterparts found version 0.5.1, readable English/Arabic RTL in light/dark themes, and no username, home path or machine name (2026-11-05).
