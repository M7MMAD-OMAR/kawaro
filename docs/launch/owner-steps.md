# Launch steps only the maintainer can do (S-072, AC8)

Nothing here has been done by an agent, and nothing here claims that anything is live. Every step is open. Texts to paste are in this folder: English `docs/launch/announcement.md`, Arabic `docs/launch/announcement.ar.md` (paste the Post section for short channels, the Release note and Rename note for longer ones). Assets and the claims table: `docs/launch/assets.md`.

1. Choose the channels for the announcement, then share the text on each one. Paste `docs/launch/announcement.md` for English channels and `docs/launch/announcement.ar.md` for Arabic ones. Attach only files listed in `docs/launch/assets.md`.
2. Create the accounts those channels need. An agent must not create accounts or enter credentials; keep credentials out of the repository.
3. Upload the GitHub social preview: repository Settings, Social preview, upload `site/og.png` (1200 x 630). Text to use for the repository description: the first sentence of the Post section in `docs/launch/announcement.md`.
4. Create the AUR account and follow `docs/distribution-channels/aur.md`.
5. Create the COPR account and follow `docs/distribution-channels/copr.md`.
