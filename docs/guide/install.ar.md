# التثبيت

## ويندوز 10 و11 (64 بت)

نزّل حزمة MSI. تُثبَّت لحسابك ولا تحتاج صلاحيات المدير. وهناك أيضا ملف ZIP محمول. البناء موقّع بشهادة اختبار ذاتية غير موثوقة، فقد يظهر [تحذير SmartScreen](site:windows).

يعرض ويندوز التطبيق باسمه الثابت Kawaro | كوارو: الجزء اللاتيني أولا في كل اللغات، ولا يتغير ترتيبه بتغير لغتك. وفي اسم ملف اختصار قائمة ابدأ يظهر الخط الفاصل بشكله العريض ｜، لأن أسماء الملفات في ويندوز لا تقبل الرمز |. أما قائمة التطبيقات المثبتة (إضافة البرامج أو إزالتها) فتعرضه باسم Kawaro وحده، وهو الاسم داخل حزمة MSI، لأن الأداة التي تبني الحزمة لا تكتب العربية.

## لينكس (64 بت)

نزّل DEB لأوبونتو وديبيان، أو RPM لفيدورا. يحتاج Nautilus إلى حزمة `nautilus-python`.

## التحقق

قارن كل ملف نزّلته بـ`SHA256SUMS`. الخطوات في [صفحة التنزيل](site:download#verify).

## أدوات إضافية

الفيديو والصوت يحتاجان FFmpeg. المستندات وPDF تحتاج LibreOffice وGhostscript. الإجراء الذي تغيب أداته لا يظهر في الخلية. شغّل `kawaro doctor` لترى الأدوات الموجودة عندك.

## من الشيفرة (لينكس)

```
git clone https://github.com/M7MMAD-OMAR/kawaro
cd kawaro
./scripts/install.sh
```

يحتاج Rust 1.85 أو أحدث. للإزالة: `./scripts/uninstall.sh`.
