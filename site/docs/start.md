# البدء السريع

1. [ثبّت](install.md) كوارو.
2. حدّد ملفا أو أكثر في مدير الملفات.
3. انقر بالزر الأيمن واختر **كوارو**. تفتح الخلية.
4. انقر على خلية. يُحفظ الناتج بجانب الأصل، والأصل لا يتغير.

يظهر التقدم في تلميح أيقونة صينية النظام. لا تظهر إلا الإجراءات التي تناسب ملفاتك والأدوات المثبتة عندك.

بعد ذلك: [استعمال الخلية](use.md) و[الصيغ](formats.md).
