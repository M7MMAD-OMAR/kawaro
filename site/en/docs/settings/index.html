    Settings

    The file is config.toml: ~/.config/sbarhive/ on Linux, %APPDATA%\SbarHive\ on Windows. Every key is optional, unknown keys are ignored, and a broken file falls back to the defaults.

    KeyValuesDefault
    languageauto, ar, enauto
    themeauto, light, darkauto
    outputbeside, subfolderbeside
    output_folderfolder name for subfolderSbarHive
    qualitylight, balanced, maxbalanced
    open_folder_when_donetrue, falsefalse
    notifytrue, falsetrue
    hive_surfaceauto, layer, windowauto
    hold_ms100 to 2000400
    portal_shortcuttrue, falsetrue
    shortcutWindows hotkeyCtrl+Alt+H
    update_checktrue, falsetrue
    update_channelstable, betastable (beta in a beta build)
    update_modeask, autoask
