    Quick start

    1. Install SbarHive.
    2. Select one or more files in your file manager.
    3. Right click and choose SbarHive. The hive opens.
    4. Click a cell. The result is saved next to the original, which is never changed.

    Progress shows in the tray tooltip. Only actions that fit your files, and the tools you have installed, appear.
