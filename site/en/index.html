Convert files from the right-click menu

Select files in your file manager and pick an action from the hive. The result is saved next to the original, and nothing leaves your machine.

Install Source on GitHub

Three steps

  1. Select

    In Dolphin, Nautilus, Nemo or Thunar, right-click and choose SbarHive.

  2. Pick a cell

    Only the actions that fit appear: by file kind, file count, and the tools you have installed.

  3. Done

    The output gets a new name in the same folder. The original stays as it was.

On Hyprland you can bind Super plus right-click to open the hive directly.

Your files stay on your machine

No uploads

Every conversion runs locally. No server receives the file, and there is no account to create.

No telemetry

SbarHive sends nothing about your files or how you use it.

Originals untouched

Output is written to a temporary file, then renamed into place. The original is never modified, and an interrupted job leaves no half-written file.

  • WAV
  • M4A

Documents and PDF

Office and ODF documents to PDF, DOCX and ODT both ways, compress, merge and rotate PDFs, turn pages into images. Needs LibreOffice and Ghostscript.

  • DOCX
  • ODT
  • XLSX
  • ODS
  • PPTX
  • ODP
  • PDF

If a tool is missing, its actions stay out of the hive. sbarhive doctor shows what was found and what is missing.

Install

SbarHive is in development and builds from source on Linux. You need Rust 1.85 or newer.

git clone https://github.com/M7MMAD-OMAR/sbarhive
cd sbarhive
./scripts/install.sh
  • The script installs for your user only, without root, adds SbarHive to the right-click menu of the file managers it finds, and starts the service with your session.
  • Nautilus needs the nautilus-python package.
  • To remove it: ./scripts/uninstall.sh

What about other tools?

File Converter

The same idea in the right-click menu, for Windows only. SbarHive starts on Linux, with Windows on its roadmap.

FFmpeg and ImageMagick

They convert almost anything from a terminal, if you know the flags. SbarHive uses FFmpeg for video and audio and puts the options in a cell.

Linux apps and extensions

Each covers a part: images only, or one task in one file manager. SbarHive handles images, video, audio and documents from one menu, in four file managers.
