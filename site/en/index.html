    Three steps, and no window to open

    1. Select files

      In Dolphin, Nautilus, Nemo or Thunar, or in Windows Explorer. Then right click and choose SbarHive.

    2. Pick a cell

      Only actions that fit the kind and number of files show up, and only those your installed tools can run.

    3. Take the result

      The result is saved under a new name in the same folder and the original stays as it was. Progress shows in the tray tooltip, never in a window that steals focus.

    On Hyprland you can bind Super plus right click to open the hive directly.

    Your files never leave your machine

    • No uploads. Every conversion runs locally. No server receives your file and there is no account to create.
    • No data collection. The app sends nothing about your files or how you use it.
    • The original is safe. Output is written to a temporary file first and renamed when complete, so the original is never touched and a stopped job leaves no half file.

    Where the project stands, honestly

    Linux

    Tested

    The hive runs on Hyprland, KDE Plasma 6 and GNOME 50, and the RPM and DEB packages install and run. Keyboard focus on real GNOME and KDE desktops is still being verified.

    Windows

    Beta, unsigned

    A per-user MSI that needs no administrator rights, a right click entry and a tray icon. It has not run on a live Windows machine yet, and SmartScreen warns because we have no signing certificate.

    Later

    Not here yet

    X11, the drop hive and notifications on Windows, and macOS. No dates are promised; the plan is public in the repository.

    We do not promise availability in any app store or package manager. What you see on the download page is what exists today.

    And the other tools?

    File Converter

    The same right click idea, but Windows only. SbarHive covers Linux and Windows with one app.

    FFmpeg and ImageMagick

    They convert nearly anything from a terminal, if you remember their options. SbarHive uses FFmpeg for video and audio and puts the options in a cell.

    File manager add ons

    Each is limited to images or to one job in one file manager. SbarHive handles images, video, audio and documents from a single menu.

    Open source

    Licensed GPLv3 or any later version. Code, bug reports and contributions live on GitHub. Adding a format takes a TOML file and a small adapter.
