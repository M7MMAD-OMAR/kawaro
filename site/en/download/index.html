Verify the file

Put SHA256SUMS in the packages folder; every file must say OK.

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows

certutil -hashfile sbarhive-0.4.0-beta.1-windows-x64.msi SHA256

If a value differs, do not run the file.

From source on Linux

git clone https://github.com/M7MMAD-OMAR/sbarhive
cd sbarhive
./scripts/install.sh

Needs Rust 1.85 or newer. To remove: ./scripts/uninstall.sh
