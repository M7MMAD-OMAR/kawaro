Pick your system

Linux

RPM and DEB, 64 bit

RPM for Fedora and its family, DEB for Ubuntu and Debian. Tested on Fedora 41 and later, Ubuntu 22.04 and 24.04, and Debian 12. The hive targets Wayland first.

GitHub releases page
Windows

MSI or ZIP, Windows 10 and 11 (64 bit)

A per-user MSI that needs no administrator rights, or a portable zip. The build is unsigned, so SmartScreen warns you. Read what that means before installing.

GitHub releases page

Pick the latest beta on that page and download SHA256SUMS with it. Windows files are named like sbarhive-*-windows-x64.msi and sbarhive-*-windows-x64.zip.

Check your download before running it

Every release lists a SHA256SUMS file. Put it in the folder with the packages; every file you downloaded must say OK.

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell)

certutil -hashfile sbarhive-0.4.0-beta.1-windows-x64.msi SHA256

Compare the output with the matching line in SHA256SUMS. Use the file name you actually downloaded.

If the value differs, do not run the file, and tell us on GitHub.

Or build it from source on Linux

You need Rust 1.85 or newer. The script installs for your account only, without administrator rights, adds SbarHive to the right click menu and starts the service at login.

git clone https://github.com/M7MMAD-OMAR/sbarhive
cd sbarhive
./scripts/install.sh
  • Nautilus needs the nautilus-python package.
  • To remove it: ./scripts/uninstall.sh

Updates

Once a day the app reads a signed manifest from the project's GitHub releases and verifies the signature against a public key built into the app before it downloads anything. More on the privacy page.
