SbarHive on Windows

The beta runs on Windows 10 and 11 (64 bit) but is not signed. This page explains why, and how to make sure your file is intact before you click Run.

Why the warning?

Windows SmartScreen shows "Windows protected your PC" for any program without a signature from a paid certificate. One person builds this project with no budget, and we have no code signing certificate yet. We do not promise a date, a particular signing programme or a place in any app store.

  1. Verify first

    Compare your file's hash with SHA256SUMS as on the download page.

  2. More info

    In the warning window click "More info" to reveal more options.

  3. Run anyway

    Click "Run anyway" only after the hash matched. If it did not, do not run it.

What is not verified yet?

Not run on a live machine

It is built on Linux and tested there. The live checklist on a real Windows machine is the next step, so you may find things we do not know about.

Missing for now

No drop hive and no notifications yet, and job progress shows only in the tray tooltip. The helper that installs an MSI update while the app is closed has not run on a live machine.

Installing

The MSI installs for your account without administrator rights and adds a SbarHive entry to the right click menu plus a tray icon. A portable zip is also available.

Updating

The app updates itself quietly for your user after checking the signature, size and hash. You can turn the automatic check off in config.toml.
