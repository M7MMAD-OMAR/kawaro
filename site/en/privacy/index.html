Privacy

No tracking, no accounts, no processing servers. Your files stay on your machine. Below is everything the app sends over the network, with no hidden exception.

What never happens

  • No file is uploaded to any server.
  • No analytics, no tracking, no automatic crash reports.
  • No account and no sign in.

The only connection: updates

A daily check

Once a day the app reads a signed manifest from the project's GitHub releases. GitHub sees your address and a fixed user agent, like any other download.

Verified before download

The signature is checked against a public key built into the app before anything is downloaded, and each package is checked against the size and SHA-256 in the manifest.

Two channels

A beta and a stable channel. A beta build follows beta, so you are offered later betas and then the final release.

Turning it off

Set update_check = false in config.toml. A manual check ignores that setting, but this beta has no menu entry or command for it yet.

The original is never touched

The result is written to a temporary file first and then atomically renamed to its final name next to the original. The original is never modified, and a stopped job leaves no half written file under a final name.

All the code is open under the GPLv3 on GitHub, so you can check for yourself.
