نزّل صبار هايف

الإصدار التجريبي الأول 0.4.0-beta.1 للينكس وويندوز. هذه نسخة بيتا: تعمل، وفيها عيوب معروفة نذكرها لك بوضوح.

0.4.0-beta.1

اختر نظامك

لينكس

RPM وDEB، 64 بت

RPM لفيدورا وعائلتها، وDEB لأوبونتو وديبيان. اختبرنا فيدورا 41 وما بعدها، وأوبونتو 22.04 و24.04، وديبيان 12. الخلية تعمل على Wayland أولا.

صفحة الإصدارات على GitHub
ويندوز

MSI أو ZIP، ويندوز 10 و11 (64 بت)

MSI لكل مستخدم بلا صلاحيات المدير، أو ملف مضغوط محمول. البناء غير موقّع، فيظهر تحذير SmartScreen. اقرأ ما يعنيه ذلك قبل التثبيت.

صفحة الإصدارات على GitHub

اختر أحدث إصدار تجريبي في الصفحة، ونزّل معه الملف SHA256SUMS. أسماء ملفات ويندوز على النمط sbarhive-*-windows-x64.msi وsbarhive-*-windows-x64.zip.

تحقق من ملفك قبل تشغيله

كل إصدار فيه ملف SHA256SUMS. نزّله في المجلد نفسه الذي فيه الحزم، ويجب أن يظهر OK أمام كل ملف نزّلته.

لينكس

sha256sum -c SHA256SUMS --ignore-missing

ويندوز (PowerShell)

certutil -hashfile sbarhive-0.4.0-beta.1-windows-x64.msi SHA256

قارن الناتج بالسطر المقابل في SHA256SUMS. غيّر اسم الملف إلى ما نزّلته فعلا.

وإن اختلفت القيمة فلا تشغّل الملف، وأبلغنا في GitHub.

أو ابنِه من الشيفرة على لينكس

تحتاج Rust 1.85 أو أحدث. يثبّت السكربت البرنامج لحسابك وحده دون صلاحيات المدير، ويضيف صبار هايف إلى قائمة النقر بالزر الأيمن، ويشغّل الخدمة عند تسجيل الدخول.

git clone https://github.com/M7MMAD-OMAR/sbarhive
cd sbarhive
./scripts/install.sh
  • يحتاج Nautilus إلى حزمة nautilus-python.
  • للإزالة: ./scripts/uninstall.sh
