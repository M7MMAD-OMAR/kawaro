تحقق من الملف

نزّل SHA256SUMS في المجلد نفسه الذي فيه الملفات، ويجب أن يظهر OK أمام كل ملف.

لينكس

sha256sum -c SHA256SUMS --ignore-missing

ويندوز

certutil -hashfile sbarhive-0.4.0-beta.1-windows-x64.msi SHA256

وإن اختلفت القيمة فلا تشغّل الملف.

البناء من الشيفرة على لينكس

git clone https://github.com/M7MMAD-OMAR/sbarhive
cd sbarhive
./scripts/install.sh

يحتاج Rust 1.85 أو أحدث. للإزالة: ./scripts/uninstall.sh
