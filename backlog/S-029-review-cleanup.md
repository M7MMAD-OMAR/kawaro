## Acceptance criteria
- AC1 (UTF-16): `#[cfg(windows)] #[doc(hidden)] pub mod win` in core has `pub fn wide(s: impl AsRef<OsStr>) -> Vec<u16>` (`encode_wide` plus a NUL) and `pub unsafe fn from_wide_ptr(p: *const u16) -> OsString`, with a `# Safety` doc section and explicit `unsafe {}` blocks in its body (edition 2024). `grep -rn 'fn wide' crates` gives 1 line. `grep -nE '\.add\(' crates/core/src/{paths,transport}/windows.rs` gives 0. `token_sid` turns the `OsString` into text with `to_string_lossy().into_owned()`. `until_nul` in `locate/windows.rs` stays (it reads a slice). `crates/core/src/win.rs` is added to `exclude_globs`.
- AC2 (`office/non_unix.rs`): no `struct Handle`, no `impl Drop` and no `CloseHandle`. The job, snapshot and thread handles are `std::os::windows::io::OwnedHandle`.
- AC3 (`Listener::bind`): it matches on the `create_instance` result. `Err(code)` goes through `bind_result(Some(code))`: `AlreadyRunning` gives `Ok(Bound::AlreadyRunning)`, and any other arm gives `Err(os_error(code))`, the same error `Failed` holds. `bind_result`'s signature is pinned, so the impossible `Listen` case stays only inside that catch-all arm. `windows.rs` has 0 `(BindOutcome::` and 0 `from_raw_os_error`. `os_error` keeps its visibility, because `windows.rs` is a child module of `transport` and already reads it.
- AC4 (`deadline.rs`, after S-028a): the one-shot flag is `Arc<AtomicBool>`. The watcher cancels only when `!flag.swap(true, SeqCst)`, and the read side takes `fired` from `flag.swap(true, SeqCst)`. `deadline.rs` has no `Mutex`.
- AC5 (lock): core has one poison-ignoring lock, `pub(crate) fn lock<T>(&Mutex<T>) -> MutexGuard<T>` in `sync.rs`, and `queue_impl.rs` loses its copy. `grep -rnE 'unwrap_or_else\((PoisonError::into_inner|\|e\| e\.into_inner\(\))\)' crates/core/src` gives 1 line. The daemon half is in AC9.
- AC6 (engines): `pub(crate) fn missing_on_not_found(e: EngineError, name: &str, url: &str, program: &Path) -> EngineError` in `office.rs`, used by `office.rs` and `pdf.rs`. `grep -c 'ErrorKind::NotFound'` in their code above `#[cfg(test)]` gives 1 in all.
- AC7 (`settings.rs`): `FormState` has `portal_shortcut: bool`, read in `state`, set in `set_state`, and mapped by `from_config` and `to_config`. Above `#[cfg(test)]` the file has no `portal_shortcut: true`, one `get_portal_shortcut` and one `set_portal_shortcut`.
- AC8 (`daemon/src/ui.rs`): `reload` uses named fields, with 0 matches for `(before|after|portal)\.[01]`. `fn token_step(step: TokenStep) -> Option<String>` is the only `HOLD_TOKEN.with` and the only `kept_token(` call. `hold_signal` tests the start once: its lines matching `\(0, 1\)|before == 0` number 1. Manager decision needed: `exclude_re` gains `"crates/daemon/src/ui.rs:.*in reload$"`, because the renamed comparisons create mutants that only `tests/drop/portal.sh` and `tests/e2e/run.sh` cover.
- AC9 (`portal_bus.rs`): `Stop` becomes `futures_util::future::{AbortHandle, Abortable}`. The file has no `struct Stop`, `AtomicWaker`, `poll_fn` or `select(`. Checked: `Abortable` is in futures-util 0.3.34 under `alloc`, and `std` turns `alloc` on, so `Cargo.toml` is unchanged and the `[[package]]` count in `Cargo.lock` is unchanged. Kept: an abort before the first poll ends the run (`abortable.rs:139`), the session is closed after a stop, and `Some(Reason::Off)` is returned. Lock: `state::lock` becomes generic, and `portal_bus::client()` calls it; the AC5 grep on `crates/daemon/src` gives 1 line.
- AC10 (unchanged tests): `cargo test --all` reports the S-028 reviewer's pass count plus this story's new tests, with 0 failed. `git diff <S-028 head> --` of `tests/`, `crates/*/tests/`, `locate.rs`, `office/tree.rs`, `cli/src/spawn.rs` and `daemon/src/portal.rs` is empty. The only edits to existing tests are the new tests and one added line, `portal_shortcut: true,`, in `form_state_of_the_defaults`. The tester makes that edit.
- AC11 (scripts, after S-028c): `scripts/windows/scope.sh` is sourced and has no side effect when sourced: it only defines the default target dir and a re-exec function that `build.sh` and `check.sh` call with `"$@"`. `make-iso.sh` uses the default only and never enters a scope. `systemd-run` and the `sbarhive-win-target` default each appear once in non-comment lines of `scripts/windows/*.sh`, both in `scope.sh`. Plain `shellcheck` (no `-x`, as `test_scripts.sh` runs it) is clean on every script, so the source line needs `# shellcheck source=/dev/null` and `scope.sh` needs `# shellcheck shell=bash`. `scope.sh` passes `bash -n` and has no long dash. `tests/windows/lib.sh` keeps its own computation of the default, because it is the test oracle.
- Every substory: AC10 for its files; the CLAUDE.md gates with no surviving mutant in changed code; `scripts/windows/check.sh` exits 0; `scripts/design-lint.sh` clean.
