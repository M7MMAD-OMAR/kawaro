# S-138 Complete DropFirst coverage and final drop position
Status: draft, awaiting baseline evidence, user clarification and Lead approval; no implementation authorized

## Story
As a file-manager user, I want DropFirst to accept throughout its promised area and open choices at my final drop position, without acting on the wrong file. Complete [S-135 AC2](<backlog/S-135-drag-ux.md#L19>), preserving [S-136 ownership](<backlog/S-136-hive-session-lifecycle.md#L7-L12>), not a new architecture.

## Acceptance criteria
- AC1: During an accepted DropFirst drag, the layer catcher retains the entire configured output input region after anchoring, hint reveal, replan and resize; hint, adjacent empty area and distant output points accept identically. Ordinary-window coverage remains the whole drop window, not the screen. Before a real drag, the bounded pointer probe remains non-stealing; choose-during-drag retains its existing region, placement and cell-only acceptance.
- AC2: Every current-generation drag Enter/Motion records the latest surface position, including repeated motions with the same cell hit. The layer handoff uses final output-local logical coordinates plus that output's logical origin exactly once, never the initial anchor, hive-offset coordinates or a cached previous session. No position gives the existing centred fallback. Existing window placement rules remain unchanged.
- AC3: Catcher closes before one normal hive opens with the exact dropped paths; zero jobs before choice, exactly one after an enabled action click. Copy-only negotiation remains: original paths, device/inodes and hashes are unchanged, output is a new file beside the source, and underlying Dolphin files/folders receive no unintended move/copy/drop. Stale-generation position, offer, motion, drop and deferred handoff events cannot move, replace or dismiss the next session. Unsupported/rejected input submits zero.
- AC4: Preserve current key-release cancellation, Escape, timeout, no-drag probe recovery and post-handoff old-release behaviour. User clarification is required before approval; this story does not reinterpret release-before-drop as permission to continue. Holding through commit causes zero reopen for 15 s; a fresh drag works once.
- AC5: Tests/replay below pass. Public guides, captions and tutorial truthfully distinguish whole-output layer from whole-window normal, with post-drop choice by default; correct affected En/Ar claims only if needed. Add one bilingual changelog line. Scoped fmt, clippy with warnings denied, touched-crate tests and design lint pass under repository resource limits. Do not claim unmeasured 150 ms budgets verified.
