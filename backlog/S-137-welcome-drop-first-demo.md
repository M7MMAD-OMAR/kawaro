# S-137 Teach drop first in the welcome captions and film
Status: done

## Story
As a new Arabic or English user, I want the Introduction captions and vector demonstration to teach the default drop-first flow, so I drop files before choosing an action instead of aiming at an action cell during the drag.

## Acceptance criteria
- AC1: Both languages describe this order in the existing five caption rows: drag a file; invoke the registered trigger; drop onto the drop area; choose an action after dropping; find the result beside the untouched original. Name the default flow explicitly, including when the saved setting is ChooseDuringDrag: this small tutorial demonstrates DropFirst, not the current setting. RightDrag, Native, Fallback and Unbound still use truthful trigger wording from the registration result; Unbound names no key and does not tell the user to drop on an action cell. Do not claim Alt works through the portal or that the whole screen accepts drops on every platform.
- AC2: The production vector film visibly distinguishes dragging, dropped-awaiting-choice, choice and result. During the drag it shows a noninteractive drop hint and zero action cells, with no highlighted or pressed action. After the drop the dragged thumbnail is absent and normal action choices appear; at least one distinct frame shows these choices with no chosen action and no result. A later pointer click chooses WEBP, and only a subsequent result phase shows photo.webp beside unchanged photo.png. Hint and action choices are never shown together. This is a simulation, not a conversion or queue submission.
- AC3: WelcomeWindow uses the same phase/pose data in its Slint FilmPose mapping, film timer and caption highlights; advancing the actual window follows AC2, not just a detached frame-description table. Play/pause and replay retain the order; reduced motion remains a static truthful poster with no running film timer. The Introduction page reached after language selection and when reopened from Settings uses the corrected film and captions. Existing pointer/centred placement and RTL mirroring remain unchanged.
- AC4: Review affected welcome/Introduction snapshots in English and Arabic, dark and light. Capture deterministic drag-hint and dropped-awaiting-choice frames as well as the affected poster/captions. At the existing minimum window size, captions and hint have no clipping or overlap and Arabic ordering is mirrored. Use existing tokens, hex components and accessible labels; no new styling primitives.
- AC5: Add one bilingual S-137 line under Unreleased. Scoped fmt, clippy with warnings denied, core/UI tests and design lint pass. No dependency, toolkit upgrade or official version bump.
