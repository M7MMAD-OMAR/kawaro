# S-078 Free distribution channels: COPR, winget, AUR, and a proper icon in the app stores
Status: approved (2026-10-26, manager)

## Story
As a user who does not use the terminal, I want to install and update Kawaro from my system's usual place, for free, so that I do not unpack files by hand.

## Decisions
1. Free channels with no review gate first: Fedora COPR (spec from the RPM build, builds on tag), winget (manifest PR to `microsoft/winget-pkgs` pointing at the MSI, generated by CI), AUR (`PKGBUILD` and `.SRCINFO`, generated by CI). Later: Ubuntu PPA. Not now: Flathub and Snap (the sandbox blocks the file manager integration and system engines). Microsoft Store only after checking its current fee.
2. The AppStream `metainfo` gets a real icon, screenshots and a release entry with the Arabic and English text, so Discover and GNOME Software show the Kawaro mark and not the generic gear. The "third party" label goes away with a signed repository (S-016).
3. Every channel is fed by the same tag workflow; nothing is uploaded by hand.

## Acceptance criteria
- AC1: `appstreamcli validate` passes on the metainfo and `appstreamcli` reports the icon and a screenshot.
- AC2: a CI job generates the winget manifest and `PKGBUILD` for a tag and validates them offline (`wingetcreate`-compatible schema, `makepkg --printsrcinfo` in a container).
- AC3: `docs/install.md` and `docs/install.ar.md` list each channel and its command, with the language switch line.
- AC4: accounts and tokens needed (COPR, GitHub fork for winget, AUR key) are listed for the maintainer in the story; nothing is published before he opens them.
