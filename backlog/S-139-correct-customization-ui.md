# S-139 Correct compact customization without moving or consuming the hive
Status: implemented, locally accepted and installed, 2026-11-05; unreleased

## Story
As a user, I want readable, exactly editable options and a reversible customization step, preserving one-click defaults and one-drop ChooseDuringDrag.

## Acceptance criteria
- AC1: Customize via pill or Shift+Return changes content in place: identical surface and global x/y/width/height, placement policy, highlighted action and pending files; no hide/show or activation. Back or first Escape, including from a focused field, discards edits and restores that normal hive with zero jobs. Reopen starts at defaults; subsequent Escape closes and clears selection.
- AC2: At 393 x 362 logical px and existing larger hive sizes, En/Ar x light/dark has zero overlapping controls/labels or clipped essential text. Replace squeezed columns with intrinsic-height stacked rows in the existing Material ScrollView; wrap long labels, scroll the body, keep footer reachable outside scrolling. Mirror RTL, retain isolated Latin digits, token styling and visible focus; accessible labels expose name/value/unit where defined.
- AC3: Every numeric schema field uses official vendored Material TextField; sliders optional. Tab/Shift+Tab reaches every field and footer; Ctrl+A/typing enters exact values; Return accepts a field without running. Existing resolver governs types/bounds/steps/defaults/clears. Empty, malformed, fractional integer and out-of-range drafts remain editable, show an error and submit zero on Run, never clamp or reuse a previous valid value. Correction, Reset and presets synchronize visible controls, resolved values and readout.
- AC4: Valid Run closes and submits exactly one job with retained files and resolved params; duplicate Run/click/Return adds zero. Invalidate each old panel on Back/Escape, rebuild, Run, close or replacement: delayed input/preview/Reset cannot change the returned hive or newer panel, including same-session reopening. Preserve S-136 terminal ownership.
- AC5: Shorten only the notification choice, e.g. "10 seconds or more" / "10 ثوانٍ أو أكثر". Keep >=10 s semantics. At 880 x 640 En/Ar x light/dark, the whole segmented group and labels fit their row without clipping/overlap or changed selection behavior.
- AC6: Evidence exercises production Slint geometry, native controls and daemon queue wiring, not detached helpers/boolean tests alone. New options matrix and native runs use frozen corrected source/build with before/after binary hashes. One-click defaults and two successive Dolphin ChooseDuringDrag drops still submit once each, without post-drop click/restart. Preserve under-150 ms show and existing preview-worker budgets.

- AC7: The mouse Customize affordance is genuinely reachable from every customizable action, including outer-ring resize-50, along a natural pointer path. It remains visible/reachable, clearly identifies the intended action, and opens that action without accidental default conversion or requiring a pointer teleport/jitter. Moving through the centre must not make the button disappear or silently customize a different action. Preserve Shift+Return and immediate plain-click/default-drop behavior. Use existing Material components and tokens; the containing hive still does not move or resize.
