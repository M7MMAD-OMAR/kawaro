# LFM3 spike fixtures

Throwaway inputs for the LFM3 spike (`docs/research/lfm3-local-models.md`, section 8). Nothing here is part of the workspace.

`actions.json`: compact catalog of the 45 real actions in `actions/*.toml` (id, accepts, label ar/en, output, min_files, skip_ext, params with type, default and range or enum). Generated by `extract_actions.py` (stdlib only, `python3 -I`). Param ranges are not in the TOML, so the script copies them from the engines (`crates/engines/src/image.rs`, `pdf.rs`, `ffmpeg.rs`) and fails if an action gets a param it has no range for.

`requests.jsonl`: 30 requests, 15 Arabic and 15 English, interleaved. Each line has `id`, `lang`, `text`, `files` (names with extensions, only to give type and count), `expected_action` and `expected_params`. Params list only what the request asks for; an omitted param means "use the action default". Ids 15, 17 and 19 are the colloquial Arabic phrasings: Syrian ("بدي ... هالفيديو", "لفّلي هالصورة") and Gulf ("ابغى ... هالـ PDF"). Ids 28, 29 and 30 expect `none` (28 ambiguous "make it look better", 29 out of scope "translate", 30 out of scope "email this"). Written by hand; `make_requests.py` rewrites the file and checks every line against `actions.json` (action exists, extension fits `accepts` and `skip_ext`, `min_files`, params in range).

`ocr/`: ten document images with a ground truth `.txt` of the same basename. All text is original (notices, a receipt, an invoice, a letter), with Western digits only. Made by `make_ocr.py` with Pillow and raqm (real Arabic shaping and RTL), then ImageMagick for the noisy pages. The `.txt` holds logical-order text, one line per rendered line; two-column pages list the first column in reading order (right column first for Arabic), tables list each row's cells joined by one space.

- `en1_clean_letter`, `ar1_clean_diacritics`: clean printed letter; the Arabic one is fully vowelized (tashkeel) with Western digits.
- `en2_small_font`, `ar2_small_font`: 15 lines at 17 to 19 px, to stress small text.
- `en3_two_columns`, `ar3_two_columns`: two columns with a divider.
- `en4_table_list`, `ar4_table_list`: ruled table with aligned numeric columns (item, qty, price, total).
- `en5_noisy_skewed`, `ar5_noisy_skewed`: phone-photo look: rotated 3 degrees, grey surround, Gaussian noise and blur (`magick -rotate -attenuate +noise Gaussian -blur`).

Notes: Noto Naskh Arabic lacks a slash glyph, so Arabic dates are written with the month name instead of `5/11/2025`. Arabic list numbers are written without a trailing dot, because a dot after a digit flips side under RTL.
